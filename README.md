# Princípios SOLID com PHP

Esse repositório tem como objetivo praticar os princípios do SOLID utilizando a linguagem PHP.

- S → [_Single Responsibility Principle_](./docs/SingleResponsibility.md)
- O → [_Open / Closed Principle_](./docs/OpenClosed.md)
- L → Liskov Substitution Principle
- I → Interface Segregation Principle
- D → Dependency Inversion Principle
